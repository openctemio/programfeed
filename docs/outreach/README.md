# Outreach to platforms

Drafts of permission requests, one per platform. **Nothing here has been sent.** The owner decides when and to whom.

A platform stays `publish: false` in [`policy/platforms.json`](../../policy/platforms.json) until a written permission is on file. Then, in one pull request: set `publish: true`, set the `attribution` text the platform asked for, and link the permission in the pull request description.

| Platform | Draft | Why we ask |
|---|---|---|
| HackerOne | [hackerone.md](hackerone.md) | the Hacker API needs an account token; no redistribution grant |
| Bugcrowd | [bugcrowd.md](bugcrowd.md) | website terms forbid redistribution |
| Intigriti | [intigriti.md](intigriti.md) | researcher API needs a token; no redistribution grant |
| YesWeHack | [yeswehack.md](yeswehack.md) | legal notices forbid redistributing platform data |
| Immunefi | [immunefi.md](immunefi.md) | terms forbid automated access without written consent |
| HackenProof | [hackenproof.md](hackenproof.md) | no official listing or redistribution statement |

Signed off in every draft as "OpenCTEM team, info@openctem.io".
